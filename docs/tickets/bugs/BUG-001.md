# BUG-001: sync.sh gagal jalan — regex salah eskep di parse_stack

Status: Open
Priority: Low
Created: 2026-07-23 20:00
Steps to Reproduce: Jalankan `bash sync.sh` dari root repo setelah docs/SRS.md punya tabel "## Tech Stack".

Issue: Di fungsi `parse_stack`, pattern `grep -v '^\|---'` dimaksudkan untuk exclude baris separator tabel markdown (`|---|---|`), tapi karena `\|` di GNU grep basic regex adalah alternation operator (bukan literal pipe), pattern ini jadi match SEMUA baris (`^` OR `---`). Akibatnya semua baris ke-filter habis, `grep -v` exit 1 (no output), dan karena `set -euo pipefail` aktif, seluruh script berhenti di situ — CLAUDE.md section stack tidak pernah ter-update otomatis.

Expected: `sync.sh` berhasil parse tabel Tech Stack dari SRS.md dan update section `<!-- STACK_START -->...<!-- STACK_END -->` di `.claude/CLAUDE.md` tanpa error.

Fix yang disarankan: ganti `'^\|---'` jadi `'^\|---'` versi literal — cukup pakai `'^\|'` tanpa backslash untuk match awalan pipe literal di BRE (`grep -v '^|---'`), atau pakai `grep -vE '^\|---'` (ERE) kalau tetap mau pakai backslash-style.
